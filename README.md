# Signum Outdoors Landing

Public GitHub Pages site for Signum Outdoors - currently just the Play Store
privacy policy page (`index.md`), used to satisfy Google Play's requirement for a
live, public privacy policy URL during closed testing.

## Publishing

1. Push this repo to GitHub.
2. In the repo's **Settings -> Pages**, set **Source** to "Deploy from a branch",
   branch `main`, folder `/(root)`.
3. Fill in the real contact email in `index.md` (currently a placeholder) before
   using the resulting URL in the Play Console listing.
